# Photography

Portrait, family, brand, product, and event photographers. The work **is** the pitch, the site is a gallery first, with the design getting out of the photography's way, then making booking easy.

## Brand voice & tone

- **Visual-first, minimal.** Let the images dominate; the UI recedes. Generous whitespace, restrained type, near-monochrome palette so photos carry the color.
- **Personal and artistic.** Photographers sell their eye and their vibe, a genuine voice and an "about me" that connects.
- Match the niche: brand/product = clean/commercial; family/portrait = warm; fine-art = editorial/gallery.

## Target keywords

- Type + place: `photographer {city}`, `family photographer {city}`, `headshot photographer {city}`, `product photographer {city}`, `brand photographer {region}`
- Service: `portrait session {city}`, `corporate headshots {city}`, `newborn photographer near me`
- Discovery: `{city} photography studio`, `senior photos {city}`

## Page set & structure

**Home · Portfolio/Galleries (by category) · About · Investment/Pricing · Booking process · Contact/Book.**

Homepage order:
1. Hero, single stunning full-bleed image (or a tasteful grid), minimal overlay, **View portfolio / Book** CTA
2. Portfolio categories, clean grid linking to galleries (the core of the site)
3. About, photographer's face, story, style/approach
4. How it works / the experience, what a session is like (reduces uncertainty)
5. Investment / pricing or "starting at" (filters leads)
6. Testimonials
7. Contact / booking inquiry + CTA

This is a deliberate cross-category combo, the validator will flag `wedding-photographer` with a warning; that's expected.
- **Template:** none yet, build from structure.

## Conversion patterns

- **The portfolio is the conversion engine**: make galleries fast, full-bleed, and easy to browse; lazy-load large images.
- **Pricing/"investment starting at"** qualifies inquiries and saves back-and-forth.
- A genuine "about" + the session experience section converts browsers into bookers.
- Simple inquiry form (date, session type, name, email) → don't over-ask.

## Compliance & credibility notes

- **Image rights/usage:** only display work you have rights to; respect client/model release terms before featuring portraits.
- Be clear on deliverables, licensing, and what packages include (prints vs. digital, usage rights for brands).
- Don't misrepresent another photographer's work as your own.
- Structure/tone guidance only.
